# Trees & Planting

The **Planting** section allows you to mass plant trees, vegetation, and other objects using simple image masks. 

1. Create a new planting layer
2. Under the layer menu, select Edit Layer.
3. Paint where you want things to be planted
4. Save your changes
5. Expand the planting layer by clicking on it
6. Select **Plant Object** to choose which tree/object to plant in that layer


## Tree Maker

You can create your own custom trees and plantable objects using our built-in Tree Maker tool using trees or vegetation assets that have multiple LOD levels as separate GLB files.

1. From the main menu select **Tools > Tree Maker**
2. Give your tree a custom name
3. Select a GLB file for LOD2 (Low) and optionally, LOD1 (High).
4. Click **Generate** for the LOD3 (Billboard)
5. Click **Export Package** to generate the final tree asset.
6. You should now be able to select your new tree from the **Custom** category when planting a new tree in a layer.
